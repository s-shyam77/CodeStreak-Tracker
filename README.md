
# ⚡ CodeStreak Tracker

A simple, responsive web app to track daily coding goals, monitor progress, and build consistent programming habits.

## ✨ Features

- Add and delete coding tasks
- Organize tasks by category
- Mark tasks as completed
- Track daily progress and completion percentage
- Calculate consecutive-day coding streaks
- Filter tasks by status
- Save tasks in browser localStorage
- Responsive dark-themed dashboard

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Browser localStorage

## 🚀 How to Run

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Add your daily coding goals and start tracking.

No additional dependencies required.

## 🎯 Purpose

Built to practice JavaScript, DOM manipulation, event handling, browser storage, and responsive web design.
